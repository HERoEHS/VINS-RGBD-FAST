# 정지 + 동적 장애물 실험 프로토콜 (SW1-1837, 07-27)

## 목적
정지한 로봇 앞에 동적 장애물(사람)이 지나갈 때 VINS가 가짜 회전/이동을 만드는지 판정.
- 가설 H-방어: 점프형(빠른 통과)은 gyro+휠 중재 + RANSAC + is_dynamic 낙인으로 방어됨
- 가설 H-취약: FOV 지배 + 저속 이동은 프레임당 ~1σ 끌림으로 누적 가능 (v9 꼬리 반례 계열)

## 녹화 준비
- 로봇을 평평한 곳에 두고 **전 구간 완전 정지** (조종기 입력 금지, 다리 동작 금지)
- ⚠️ **/dev/shm에 녹화 후 복사** (디스크 직녹화는 CM 스톨 글리치 이력 — [[edie-wheel-odom-glitch]])
- 토픽: 기존 edie_gate_verify 시리즈와 동일 세트 (카메라 image_gray + depth + offset_imu + diff_drive odom + joint_states + tf)
- 조명: 평소 검증 장소와 동일 조건 권장

## 안무 (총 ~100초, 시각은 대략이면 됨 — 분석이 자동 구간 감지)
| 구간 | 시간 | 행동 | 검증 대상 |
|---|---|---|---|
| P0 기준 | 0~15s | 아무도 없음 (init + 조용한 기준선) | 무간섭 안정도 |
| P1 원거리 | 15~30s | 사람이 **2~3m 거리**에서 보통 속도로 좌우 1왕복 | 배경 다수 조건 (RANSAC 방어) |
| P2 근접 저속 ★핵심 | 30~55s | 사람이 **0.5~1m 앞**에서 **아주 천천히** 좌→우, 우→좌 각 1회 (편도 ~8초, FOV를 몸으로 크게 가리며) | 취약 가설의 표적 조건 |
| P3 근접 고속 | 55~70s | 같은 거리에서 **빠르게** 좌우 2왕복 | 점프형 방어 확인 |
| P4 지속 점유 | 70~85s | 카메라 바로 앞(0.5m)에 **서서** 몸을 천천히 흔들기 (FOV 지속 지배) | 최악 조건 (특징 고갈/끌림) |
| P5 회복 | 85~100s | 아무도 없음 | 오차 잔존 vs 복원 판정 |

## 판정 기준 (분석 스크립트가 출력)
- 참값 = 전 구간 위치·yaw 불변 (정지)
- 합격: 전 구간 |Δyaw| < 1° 및 |Δxy| < 0.03m (재생 노이즈 수준)
- 취약 실증: P2/P4에서 |Δyaw| ≥ 2° 또는 |Δxy| ≥ 0.05m 단조 누적, P5에서 미복원
- 낙인 활동은 est 로그 + P2 구간 흔들림의 시간 상관으로 간접 판독
